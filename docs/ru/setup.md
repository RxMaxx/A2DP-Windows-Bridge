## Требования

- **Windows 10 (22H2) / 11** (x64 или ARM64)
- **USB-адаптер Bluetooth для BlueCaster**: рекомендуется отдельный донгл; встроенный USB-адаптер тоже подойдёт, но тогда у Windows не останется собственного Bluetooth (см. [Шаг 2](#winusb))

BlueCaster сам назначает адаптеру драйвер WinUSB. [Zadig](https://zadig.akeo.ie/) больше не нужен (он по-прежнему работает, см. [Использование Zadig](#zadig)).

## Установка BlueCaster

Каждый [выпуск](https://github.com/SeiyaFunaokaJP/BlueCaster/releases) выходит в двух вариантах с одними и теми же файлами:

- **Установщик** (`BlueCaster-<version>-win64-setup.exe`, для ARM64 — `-arm64-setup.exe`): устанавливает программу для текущего пользователя без прав администратора, добавляет пункт в меню «Пуск» (**BlueCaster**) и программу удаления, а также устанавливает Microsoft Edge WebView2 Runtime, если её нет (в Windows 11 она уже есть). Обновления устанавливаются из самого приложения (**Параметры > Обновления > Обновить сейчас**). Программы размещаются в `%LOCALAPPDATA%\BlueCaster\` (три программы, программа удаления и папка `licenses\` с текстами лицензий)
- **Портативная версия** (`BlueCaster-<version>-win64-portable.zip`, для ARM64 — `-arm64-portable.zip`): распакуйте в любое место и запустите `bluecaster.exe`. Держите три программы (`bluecaster.exe`, `bluecaster-core.exe`, `bluecaster-driver.exe`) вместе. Портативная копия только сообщает об обновлениях; для неё нужна установленная WebView2 Runtime

Оба варианта хранят настройки, профили, ключи связи и прошивки в `%APPDATA%\BlueCaster`, поэтому между ними можно переключаться. При удалении эта папка удаляется, если вы не снимете флажок **Удалить данные пользователя** (при тихом удалении она сохраняется).

### Переход с v1 {#from-v1}

Запустите установщик поверх v1. На его странице **Всё готово к установке** указано, какие предыдущие версии он сначала удалит (v1 или любую 2.0.x). Он попросит закрыть v1, если она запущена, затем удалит v1 и сохранит папку настроек: профили, сопряжение с наушниками и файлы прошивки переносятся, и наушники не нужно сопрягать заново. Адаптер, которому уже назначен WinUSB (через Zadig), сохраняет его. Если был включён параметр **Запускать вместе с Windows**, теперь запускается v2.

При первом запуске v2 копирует настройки v1 в `%APPDATA%\BlueCaster\backup\v1\`, прежде чем прочитать их.

### Переход с 2.0.x (A2DP Windows Bridge) {#from-2x}

BlueCaster 3.0.0 — это новое название A2DP Windows Bridge. Запустите установщик 3.0.0 поверх установленной 2.0.x: программа установки сама удалит старую версию и сохранит ваши настройки. Пункт в меню «Пуск» и запись **Запускать вместе с Windows** переходят на «BlueCaster».

При первом запуске 3.0.0 переименовывает папку `%APPDATA%\A2DPWB` в `%APPDATA%\BlueCaster` и раскладывает её файлы по вложенным папкам (см. [Настройки и файлы](architecture#settings-and-files)). В `backup\v2\` хранится копия настроек и сопряжений 2.0.x, чтобы можно было снова установить 2.0.2: скопируйте эти файлы обратно в `%APPDATA%\A2DPWB`.

Наушники могут показывать старое имя Bluetooth «A2DPWB», пока вы не выполните сопряжение заново.

## Шаг 1. Настройка при первом запуске {#first-run}

Подключите USB-адаптер Bluetooth и запустите BlueCaster. При первом запуске (аудиоустройств ещё нет или ни у одного адаптера нет WinUSB) BlueCaster открывает **Мастер настройки** из четырёх шагов. После того как мастер пройден или пропущен, сам он больше не открывается: устройства добавляются на экранах **Главная** или **Аудиоустройства**.

1. **Выбор адаптера**: найденные USB-адаптеры Bluetooth. Если вашего нет, подключите его и нажмите **Обновить**. Зелёная метка **Поддерживается** или красная **Не поддерживается** показывает, может ли BlueCaster использовать адаптер; неподдерживаемый адаптер отображается в списке, но выбрать его нельзя
2. **Драйвер и прошивка**: шаг перечисляет, что будет сделано, а кнопка **Настроить этот адаптер** это выполняет: заменяет драйвер адаптера на WinUSB (Windows запросит права администратора, см. [Шаг 2](#winusb)) и скачивает нужные адаптеру файлы прошивки Realtek (см. [Прошивка](#firmware)). Прошивку, которую BlueCaster скачать не может, кладут в папку прошивки вручную. Если в Windows через этот адаптер сопряжены устройства (например, клавиатура или мышь на встроенном адаптере), кнопка сначала называет их: они перестанут работать с Windows, пока BlueCaster использует адаптер, а **Отмена** их сохраняет. Устройства с собственным USB-приёмником это не затрагивает; чтобы сохранить остальные, используйте BlueCaster с отдельным USB-адаптером. Кнопка **Заменить на драйвер WinUSB** на экране **Адаптеры** тоже их называет
3. **Поиск аудиоустройств**: поиск запускается сам. Переведите аудиоустройство в режим сопряжения и нажмите **Подключить** рядом с ним (или введите его адрес и нажмите **Использовать**): BlueCaster сохраняет устройство с лучшим доступным для него кодеком («Авто») и подключается. После этого оно появляется в разделе **Сопряжённые устройства** с точкой, показывающей его состояние, а поиск останавливается. **Добавить устройство** отключает его и возобновляет поиск следующего устройства; оно остаётся сохранённым, а ошибочно добавленное устройство можно там удалить. **Импортировать сопряжения из Windows** появляется, если Windows сопрягала устройства через этот адаптер: кнопка **Импортировать** выводит их список, все с флажками (см. [Шаг 3](#headphones)). **Далее** работает и без устройства; аудиоустройства можно добавить позже на экране **Аудиоустройства**. Новые устройства захватывают **Hi-Fi Cable**, если он установлен, иначе VB-CABLE: Hi-Fi Cable даёт наименьшую задержку, поэтому его рекомендуется использовать для звука, а VB-CABLE — для микрофона наушников. Пока какого-то кабеля нет, шаг показывает предупреждение; его ссылка **Подробнее** перечисляет оба кабеля: **Установить** у VB-CABLE скачивает пакет VB-CABLE с сайта VB-Audio (1,3 MB) и устанавливает его (запрос прав администратора; если он не появился, перезагрузите Windows), а **Скачать** у Hi-Fi Cable открывает страницу VB-Audio. У установленного кабеля там вместо этого есть кнопка **Удалить**. Оба — donationware от VB-Audio ([vb-cable.com](https://vb-cable.com/)), как указано на экране **О программе**: BlueCaster не включает VB-CABLE, а пожертвования идут VB-Audio. В компании или другой организации VB-Audio просит приобрести лицензию на каждую установку ([лицензирование](https://vb-audio.com/Services/licensing.htm)). Когда BlueCaster впервые обнаружит кабель позже, устройства с источником **Устройство по умолчанию** начинают захватывать его (VB-CABLE — только пока не установлен Hi-Fi Cable), а устройства, у микрофона которых нет рабочего выхода, начинают воспроизводить микрофон в него. Кодек можно позже изменить на экране **Кодеки**
4. **Общие настройки**: тема, **Запуск**, **Уведомления** и проверка обновлений — те же элементы, что и в параметрах, сохраняются сразу. Первая настройка включает **Запускать вместе с Windows** и **Запускать в области уведомлений**

**Настроить позже** пропускает остальные шаги; **Параметры > Запустить настройку** снова открывает мастер.

## Шаг 2. Назначение адаптеру драйвера WinUSB {#winusb}

BlueCaster обменивается данными с USB-адаптером Bluetooth напрямую через WinUSB — универсальный драйвер USB, входящий в Windows. Рекомендуется **отдельный адаптер** — тогда встроенный Bluetooth продолжает обычно работать для Bluetooth Windows.

1. Откройте экран **Адаптеры** (шаг мастера **Драйвер и прошивка** выполняет шаги 2--4 кнопкой **Настроить этот адаптер**)
2. В строке **Драйвер** адаптера указано **Исходный драйвер** (или **Нет драйвера**): драйвер, установленный Windows или производителем, который заменит WinUSB. Нажмите **Заменить на драйвер WinUSB**
3. Прочитайте подтверждение и продолжите: Windows запросит права администратора (UAC)
4. Теперь в строке драйвера указано **Драйвер WinUSB**

Если Windows не смогла сразу загрузить WinUSB (адаптер был занят), BlueCaster сообщает об этом, а в строке драйвера отображается **Переподключите адаптер или перезагрузите Windows**. Отключите адаптер и подключите его снова; если адаптер встроенный, перезагрузите Windows. До этого подключение завершается ошибкой `failed to initialize WinUSB (error 50)` в журнале.

{: .warning }
Пока назначен WinUSB, собственный Bluetooth Windows не видит адаптер: устройства, сопряжённые с Windows через него, не работают, пока драйвер не будет восстановлен. Для обычной периферии (клавиатура, мышь и т. д.) используйте встроенный Bluetooth. Встроенный адаптер, который является USB-устройством (на многих ноутбуках это адаптер Realtek), тоже можно отдать BlueCaster, но тогда **у ПК совсем не будет Bluetooth Windows** (параметры Bluetooth, мыши, клавиатуры, другие аудиоустройства), пока вы не восстановите его драйвер.

**Восстановить исходный драйвер** на том же экране возвращает адаптер Windows: Windows снова выбирает собственный драйвер (обычно свой драйвер Bluetooth), и адаптер работает с Bluetooth Windows. BlueCaster не сможет передавать через него звук, пока WinUSB не будет назначен снова. Windows одновременно работает только с одним адаптером Bluetooth: если используется другой, BlueCaster сообщает об этом после восстановления, и этот адаптер заработает в Windows, только когда вы отключите тот в диспетчере устройств и переподключите этот. У наушников, которые BlueCaster сопряг заново, новый ключ: при восстановлении он передаётся и Windows — для тех устройств, которые Windows сопрягла через этот адаптер, — поэтому они подключаются там без повторного сопряжения. **Ограничение:** передаются только классические сопряжения, но не ключи LE: устройство, которое Windows использует через LE (LE Audio), нужно сопрячь в Windows заново (в режиме разработчика можно попробовать передать их: **Разработчик > Отладка**). Программа удаления предлагает то же самое: на одной из страниц мастера удаления есть **Восстановить исходный драйвер Bluetooth** (если BlueCaster переводил адаптеры на WinUSB; один запрос прав администратора) и **Удалить данные пользователя** (настройки, кодеки, сопряжения и прошивки в `%APPDATA%\BlueCaster`, а также то, что запоминает окно, например **Показывать только поддерживаемые кодеки**); оба флажка по умолчанию установлены. Если WinUSB назначен только адаптерам без такой записи (через Zadig или v1), первый вариант присутствует, но не отмечен: тогда драйвер для них выбирает Windows. Обновления сохраняют WinUSB, как и тихое удаление (`/S`). На той же странице предлагаются **Удалить VB-CABLE** и **Удалить Hi-Fi Cable**, если они установлены; по умолчанию они не отмечены, так как кабели могут использовать другие приложения; кабели удаляются без окна программы установки VB-Audio, а Windows запрашивает права администратора. Затем Windows обновляет конфигурацию оборудования, и кабель исчезает из списка звуковых устройств; перезагрузка предлагается, только если он всё ещё в списке.

### Использование Zadig {#zadig}

Драйвер WinUSB, установленный с помощью [Zadig](https://zadig.akeo.ie/), работает так же хорошо:

1. Откройте Zadig и выберите **Options > List All Devices**
2. Выберите свой USB-адаптер Bluetooth в раскрывающемся списке
3. Выберите **WinUSB** в качестве целевого драйвера и нажмите **Replace Driver**

### Вручную в диспетчере устройств {#device-manager}

Если адаптера нет в списке BlueCaster, кнопка на экране **Адаптеры** не срабатывает или ваш адаптер ведёт себя не так, как другие адаптеры того же типа, то же самое можно сделать вручную в диспетчере устройств Windows (щёлкните правой кнопкой **Пуск** > **Диспетчер устройств**). Для обоих действий нужны права администратора. Названия пунктов меню в разных версиях Windows могут немного отличаться.

**Заменить на драйвер WinUSB**

1. Найдите адаптер: обычно он находится в разделе **Bluetooth** под собственным именем (например, «TP-Link Bluetooth USB Adapter») или отмечен жёлтым значком, если его драйвер не запустился. **Вид > Устройства по подключению** помогает отличить его от встроенного Bluetooth компьютера, который трогать не нужно, если только вы не хотите отдать его BlueCaster
2. Щёлкните его правой кнопкой > **Обновить драйвер** > **Найти драйверы на этом компьютере** > **Выбрать драйвер из списка доступных драйверов на компьютере**
3. Если Windows спросит тип устройства, выберите **Устройства USB**. Снимите флажок **Только совместимые устройства**, выберите изготовителя **WinUsb Device** и модель **WinUsb Device**, нажмите **Далее** и подтвердите предупреждение
4. Теперь адаптер отображается как **WinUsb Device** в разделе **Устройства USB**. Перезапустите BlueCaster (или снова откройте экран **Адаптеры**): он будет использовать адаптер так же, как с Zadig

**Восстановить исходный драйвер**

1. В разделе **Устройства USB** щёлкните адаптер (**WinUsb Device**) правой кнопкой > **Удалить устройство**. Если драйвер WinUSB был установлен через Zadig, установите также флажок **Попытаться удалить драйвер для этого устройства**, иначе Windows снова выберет драйвер Zadig
2. Отключите адаптер и подключите его снова (или **Действие > Обновить конфигурацию оборудования**). Windows установит собственный драйвер, и адаптер появится в разделе **Bluetooth**
3. Если вместо этого он отмечен там жёлтым значком (его драйвер не запустился, например код 31), драйвер производителя с ним не работает: щёлкните правой кнопкой > **Обновить драйвер** > **Найти драйверы на этом компьютере** > **Выбрать драйвер из списка доступных драйверов на компьютере** > **Generic Bluetooth Adapter** или снова назначьте WinUSB, как описано выше, чтобы использовать адаптер с BlueCaster

## Шаг 3. Поиск наушников {#headphones}

**Найти устройства** (на экране **Аудиоустройства**) в течение 30 секунд ищет устройства поблизости с помощью USB-адаптера и выводит их по мере ответа. В мастере настройки поиск запускается сам и продолжается, пока не будет подключено устройство (**Добавить устройство** отключает его и возобновляет поиск), не будет нажата кнопка **Остановить поиск** или не будет закрыт мастер. Сначала переведите наушники в режим сопряжения. Устройства, с которыми BlueCaster уже выполнял сопряжение, отмечаются как **Сопряжено**.

Если поиск их не находит, введите адрес Bluetooth в поле **Вручную:** и нажмите **Использовать**. Введённые или вставленные адреса форматируются по мере ввода: `AA:BB:CC:DD:EE:FF`, `aa-bb-cc-dd-ee-ff`, `AABBCCDDEEFF` и `AA BB CC DD EE FF` — все превращаются в `AA:BB:CC:DD:EE:FF`.

Наушники, которые Windows сопрягла через этот адаптер до назначения ему WinUSB, могут сохранить это сопряжение: **Импортировать сопряжения из Windows** (на шаге мастера с устройствами; отображается, если такие устройства есть) выводит их список, все с флажками, и переносит отмеченные, так что они подключаются без режима сопряжения. Windows запросит права администратора. Такое устройство обычно не находится в режиме сопряжения и не появляется при поиске; если же оно появилось или вы ввели его адрес, **Подключить** или **Добавить** сначала предупреждает, что оно сопряжено в Windows; **Всё равно добавить** выполняет сопряжение заново, как с новым устройством.

**В параметрах Windows** (если наушники были сопряжены со встроенным Bluetooth компьютера):
1. Откройте **Параметры > Bluetooth и устройства**
2. Выберите своё аудиоустройство
3. Нажмите **Свойства**
4. Будет показан адрес Bluetooth (формат: `AA:BB:CC:DD:EE:FF`)

**Из командной строки** (сначала закройте BlueCaster: область уведомлений > **Выход**):
```
bluecaster-core.exe --cli --scan
```

Наушники начинают с кодеком **Авто** (**Кодеки**) и системным звуком в качестве источника вывода (**Аудиоустройства**); значения по умолчанию дают наилучший звук. Обо всём остальном см. [Использование](usage).

## Прошивка (адаптеры Realtek) {#firmware}

Для работы USB-адаптеров Bluetooth на чипах Realtek (например, TP-Link UB500, донглов на RTL8761BU) нужна проприетарная прошивка. Адаптерам CSR прошивка не нужна. Адаптерам Intel, MediaTek MT79xx, Qualcomm и Broadcom могут понадобиться собственные файлы прошивки: см. [Рекомендуемые адаптеры](#adapters).

### В приложении (пошаговое скачивание)

Экран **Адаптеры** (и шаг мастера **Драйвер и прошивка**) показывает прошивку адаптера: **Прошивка в порядке**, **Файлы Realtek не нужны** (адаптер, который BlueCaster не распознаёт, с чипом **Не Realtek**) или **Прошивка не найдена** с именами нужных файлов. Кнопка **Открыть страницу загрузки** открывает в браузере страницу [linux-firmware/rtl_bt](https://git.kernel.org/pub/scm/linux/kernel/git/firmware/linux-firmware.git/tree/rtl_bt), а затем **Открыть папку прошивки** открывает папку назначения. Скачайте нужные файлы `.bin` и поместите их в папку прошивки.

У адаптера другого производителя нет выбора **Чип Bluetooth**; его метка говорит, откуда берётся прошивка: **Из драйвера MediaTek** или **Из драйвера Qualcomm** (читается из драйвера производителя для Windows, который остаётся установленным после WinUSB), **Из драйвера Wi-Fi** (Marvell; не выключайте Wi-Fi), **Из папки прошивки** (Intel, с кнопками **Открыть страницу загрузки**, **Открыть папку прошивки** и **Руководство по настройке**), **Необязательно** (`.hcd` от Broadcom) или **Не требуется** (CSR, Barrot, Actions). Когда BlueCaster загрузил её через WinUSB, метка показывает **Загружена**, а если загрузить не удалось — **Не загружена**, с кнопками **Открыть страницу загрузки**, **Открыть папку прошивки** и строкой о том, откуда берётся прошивка.

Для чипов из списка **Чип Bluetooth** кнопка **Скачать прошивку** сделает всё за вас: после подтверждения BlueCaster скачивает файлы из linux-firmware (kernel.org), сверяет каждый с ожидаемой суммой SHA-256 и сохраняет в папку прошивки. Чип, для которого в linux-firmware нет файла конфигурации, получает пустой `_config.bin` (тогда чип использует собственные настройки). Эти файлы не входят в BlueCaster; они скачиваются только по вашему запросу.

BlueCaster определяет чипсет адаптера и показывает, какие файлы прошивки нужны.

Без прошивки адаптер Realtek всё равно открывается и отвечает на коде из ПЗУ, поэтому выглядит исправным, но подключение или передача звука завершаются ошибкой. Тогда BlueCaster сообщает, что прошивка не загружена. Модуль сохраняет прошивку, загруженную в предыдущем сеансе, пока не будет обесточен, поэтому даже без файлов он может продолжать работать, пока ПК не перезагрузится или адаптер не будет отключён.

### Параметр «Чип Bluetooth»

Список **Чип Bluetooth** на экране **Адаптеры** определяет, выполняет ли BlueCaster инициализацию Realtek (загрузку прошивки) на адаптере:

| Вариант | Значение |
|:--------|:---------|
| **Авто** (по умолчанию) | Определяется по обнаруженному адаптеру при каждом запуске BlueCaster. Известный адаптер Realtek получает свой чип; для любого другого адаптера инициализация Realtek не выполняется |
| **Не Realtek** | Никогда не выполнять инициализацию Realtek. Используйте для адаптеров Intel, Broadcom, CSR и других, если «Авто» не распознаёт ваш |
| **RTL8761BU**, **RTL8822CU**, ... | Этот чип Realtek. Нужен для адаптера на чипе Realtek, который «Авто» не распознаёт (продукт OEM под собственным VID:PID). Строка состояния показывает, есть ли его файлы `.bin` в папке прошивки |
| **Custom** | Использует `custom_fw.bin` и `custom_config.bin` из папки прошивки |

Не выбирайте чип Realtek или Custom для адаптера не на Realtek: BlueCaster попытается загрузить в него прошивку Realtek, и адаптер может не запуститься.

### Скачивание вручную

1. Скачайте файлы прошивки и конфигурации `.bin` для своего чипсета из [linux-firmware/rtl_bt](https://git.kernel.org/pub/scm/linux/kernel/git/firmware/linux-firmware.git/tree/rtl_bt) (например, `rtl8761bu_fw.bin` и `rtl8761bu_config.bin`)
2. Поместите оба файла в папку прошивки BlueCaster (`%APPDATA%\BlueCaster\firmware`, её также открывает **Открыть папку прошивки**)

{: .note }
Эти файлы прошивки — проприетарные двоичные файлы Realtek, распространяемые через проект linux-firmware. В этот репозиторий они не входят. Условия распространения см. в [WHENCE](https://git.kernel.org/pub/scm/linux/kernel/git/firmware/linux-firmware.git/tree/WHENCE).

## Рекомендуемые адаптеры {#adapters}

Какие адаптеры и наушники действительно использовались с BlueCaster, с кодеками и отчётами: [Проверенное оборудование](hardware).

| Чипсет | Примеры продуктов | Примечания |
|:-------|:------------------|:-----------|
| Realtek | TP-Link UB500, RTL8761BU | Требуется скачать прошивку (см. выше). Проверен лучше всего |
| Realtek | RTL8852BD, встроенный в ноутбуки (`0BDA:B853`) | В linux-firmware для него нет прошивки: BlueCaster читает `rtl8852bd_mp_chip_new.dat` из драйвера Bluetooth Realtek для Windows, поэтому не удаляйте этот драйвер (или поместите файл в папку прошивки). На оборудовании ещё не проверялся |
| CSR | Типовые донглы CSR8510 | Работают сразу, прошивка не нужна |
| Barrot | Донглы Bluetooth 5.4 / 6.0 (`33FA:0010`, `33FA:0012`) | Работают на прошивке из ПЗУ, прошивка не нужна. Пока один отчёт пользователя |
| Marvell | Встроенный в Microsoft Surface Pro / Surface Book (88W8897) | Файлы прошивки не нужны: драйвер Wi-Fi загружает и прошивку Bluetooth, поэтому не выключайте Wi-Fi. На оборудовании ещё не проверялся |
| Actions | Донглы ATS2851 (`10D7:B012`) | Работают на прошивке из ПЗУ, прошивка не нужна. Сообщает о командах, которые не умеет выполнять; BlueCaster их скрывает. На оборудовании ещё не проверялись |
| Broadcom | ASUS BT400 (BCM20702) | Адаптеры, сообщающие вендорный класс `FF/01/01` вместо класса Bluetooth `E0/01/01` (OEM-донглы на BCM20702), тоже распознаются. Работает на прошивке из ПЗУ; необязательный файл PatchRAM `.hcd` (например, `BCM20702A1-0b05-17cb.hcd`) в папке прошивки загружается при запуске |
| Intel | Intel 7260 / 3160 / 7265 / 3165 / 3168 / 8260 / 8265 / 9260 / AX200 / AX201 / AX210 / AX211 | В режиме загрузчика (например, после холодного запуска) нужны соответствующие `ibt-*.sfi` + `ibt-*.ddc` из `intel/` в linux-firmware в папке прошивки; журнал называет их (например, `ibt-0180-0041.sfi`). 7260 / 3160 / 7265 / 3165 / 3168 работают из ПЗУ и файлов не требуют; соответствующий патч `ibt-hw-*.bseq` из той же папки применяется, если он есть |
| MediaTek | MT7925, MT7927, MT7922, MT7921, MT7902 (карты Wi-Fi, например AMD RZ717, RZ738, RZ616, RZ608) | Нужен файл чипа `BT_RAM_CODE_MT*_hdr.bin` (например, `BT_RAM_CODE_MT7925_1_1_hdr.bin`), который BlueCaster читает из драйвера Bluetooth MediaTek для Windows, если он установлен; иначе поместите файл из `mediatek/` в linux-firmware в папку прошивки; журнал называет его. MT7927 на оборудовании ещё не проверялся |
| Qualcomm | QCA61x4, QCA9377 (ROME), WCN6855 (FastConnect 6900) | Нужны rampatch и NVM чипа (например, `AthrBT_0x00000302.dfu` и `ramps_0x00000302_48.dfu`), которые BlueCaster читает из драйвера Bluetooth Qualcomm для Windows, если он установлен; иначе поместите файлы из `qca/` в linux-firmware (`rampatch_usb_*.bin`, `nvm_usb_*.bin`) в папку прошивки; журнал называет их. На оборудовании ещё не проверялись |
| MediaTek, Qualcomm | Более старые чипы MediaTek (например, MT7663), другие чипы Qualcomm (QCA6290, WCN785x) | Не поддерживаются: нужны загрузчики прошивки, которых в BlueCaster нет ([помогите добавить](chip-support)) |

Для кодеков с высоким битрейтом, таких как LDAC, обычно лучше всего подходят USB-адаптеры Bluetooth 5.0+.

Если WinUSB назначен нескольким адаптерам, BlueCaster использует первый найденный. Оставляйте WinUSB только на адаптере, который используете для BlueCaster.
