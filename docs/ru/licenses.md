# Лицензии

BlueCaster распространяется по двойной лицензии: на ваш выбор **Apache License 2.0** или **MIT License** (SPDX `Apache-2.0 OR MIT`). См. [LICENSE](https://github.com/SeiyaFunaokaJP/BlueCaster/blob/main/LICENSE), [LICENSE-APACHE](https://github.com/SeiyaFunaokaJP/BlueCaster/blob/main/LICENSE-APACHE) и [LICENSE-MIT](https://github.com/SeiyaFunaokaJP/BlueCaster/blob/main/LICENSE-MIT).

{: .warning }
Распространяемый `bluecaster-core.exe` содержит [BTstack](https://github.com/bluekitchen/btstack), лицензия которого разрешает использование и распространение только в **личных некоммерческих целях**. BlueCaster распространяется только как единый набор своих программ, поэтому это ограничение действует для всего выпуска. Коммерческие лицензии можно получить у BlueKitchen GmbH.

Сторонние компоненты (BTstack, libldac, libopenaptx, fdk-aac, кодировщик LHDC V5, libopus, кодировщик aptX Adaptive, крейты Rust, SolidJS и другие), их зафиксированные версии, лицензии, обязательства, а также сведения о патентах, товарных знаках и сертификации собраны в одном месте: **[THIRD_PARTY_LICENSES.md](https://github.com/SeiyaFunaokaJP/BlueCaster/blob/main/THIRD_PARTY_LICENSES.md)**. Установщик и портативный ZIP-архив поставляют его вместе с текстами лицензий в папке `licenses/` рядом с программами, а раздел **О программе** ссылается на копию для каждой версии.
